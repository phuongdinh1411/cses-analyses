# Hello Interview — System Design Problem Breakdowns

> Source: [hellointerview.com/learn/system-design/problem-breakdowns](https://www.hellointerview.com/learn/system-design/problem-breakdowns)
>
> 32 problems total — 16 official full solutions (crawled) + 16 AI-generated full solutions following the same template.

Each problem follows the **Hello Interview Delivery Framework**:
1. Functional & Non-Functional Requirements + Constraints/Estimates
2. The Set Up: Core Entities + API Design
3. High-Level Design (one section per functional requirement)
4. Potential Deep Dives (Bad / Good / Great solutions with trade-offs)
5. Final Design (architecture diagram)
6. What is Expected at Each Level (Mid / Senior / Staff+)
